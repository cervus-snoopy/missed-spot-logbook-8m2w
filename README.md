A deadpan robot vacuum files a one-line status log explaining why one spot was missed: the dust relocated behind the sofa and filed a formal complaint, so firmware 4.2 requires the vacuum to respect its new address.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

This writes a single 156-character line to `entry.txt` (UTF-8, no trailing newline).
